# GraphMyTrade Windows Releases

This public repository distributes official GraphMyTrade Windows installer binaries and signed update manifests only.

The source code is private. Never upload source files, publisher private keys, customer data, API credentials, or passwords here.

Once release verification and Windows QA are complete, stable releases contain `GraphMyTrade-Setup-X.Y.Z.exe` and its signed `update.json`.

Current local desktop features require no subscription or license activation.
