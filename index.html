GOOD TO KNOW

Clear answers.
No surprises.

What to expect before you connect or install.

Do I need to know coding?+

No. GraphMyTrade is designed to make supported broker API workflows and manual trade journaling approachable without coding.

Will it work without a broker API?+

The manual trading journal works without a broker API. API-dependent tools require compatible data and permissions.

Does it support every broker and market?+

No. Supported tools vary with each broker's API, available data and account permissions. Compatibility should be verified before use.

Is this a broker or automated trading service?+

No. GraphMyTrade is an independent Windows desktop research and journaling toolkit, not a broker, managed trading service or guaranteed-results system.

Can it automatically close positions or activate a kill switch?+

Broker-supported automatic trading controls require separate integration and testing. These capabilities must not be assumed available.

Where is the official Windows installer?+

Use the official download page. A verified release link and confirmed licensing details will appear once available.
