# GraphMyTrade 99 Shop — Instamojo + Google Sheets (staging)

STATUS: Code only. NOT deployed; no merchant account linked; no live product, order or payment test. The existing production website and sweet-voice-3fdf Worker are unchanged.

## Simple architecture

Existing GraphMyTrade website remains the SEO storefront. A PUBLIC Google Sheets CSV holds only approved product metadata, titles, categories, descriptions, prices, product cover URLs, and Instamojo checkout links. A free-tier Cloudflare Worker reads the sheet, renders SEO product pages and a sitemap, and provides the catalog to the existing storefront. Instamojo hosts the actual downloadable files, collects payment and sends the purchased download by email.

No R2, D1, Google Drive sharing, private admin dashboard or home-built payment webhook is required for this version. You may keep backups privately on Google Drive; buyer delivery uses Instamojo's hosted digital goods.

## What the account owner must do

1. Open https://www.instamojo.com/ and log in or create a merchant account. Complete required KYC and bank verification.
2. In the merchant dashboard use Add Product -> Digital Product. Upload the deliverable itself, set the title, description and fixed INR price. Do NOT use an ordinary payment request link: it may not include automatic file delivery.
3. Review automatic buyer download and email settings, save the product, and copy the real Instamojo product checkout URL. Use the Digital Product Link, not a generic store homepage.
4. Before launch verify the actual Instamojo plan's digital-file transaction fees, payment activation and a successful buyer email/download using an approved test transaction.
5. Match the Google Sheet price exactly to the Instamojo checkout price. Editing a Sheet does NOT modify Instamojo prices.

Reference: https://support.instamojo.com/hc/en-us/articles/208531995-How-to-create-a-digital-product-link

## Google Sheets product manager

Make a separate spreadsheet containing ONLY approved public product information. The template is PRODUCT-SHEET-TEMPLATE.csv. Do not publish customer data, private drafts, paid-file URLs, tokens, bank data or internal files.

Column headers: slug, title, description, category, format, priceInr, status, instamojoUrl, cover, seoTitle, seoDescription, keywords, includes, compatibility, license, addedAt.

Only products with status=published, integer price ₹1–₹99, a valid Instamojo link, category and format will be shown. Each slug must be unique, lowercase, and hyphen-separated. Use | between the included items/keywords. Cover is an HTTPS image URL or /assets/... image path, NEVER a link to the paid file.

To publish public product metadata: Google Sheets -> File -> Share -> Publish to web -> choose ONLY the public catalog sheet -> CSV. The resulting CSV URL is inserted into Cloudflare Worker variable SHEET_CSV_URL. Do not enable public spreadsheet editing.

The Worker caches the public catalog for about 2 minutes. Explicit owner approval of every individual product is still required before you mark it published.

## Preview only — requires your PC

From the shop-platform/instamojo folder run: node --test test/catalog.test.mjs
Then copy wrangler.toml.example to wrangler.toml, add the public SHEET_CSV_URL, run npx wrangler login and npx wrangler deploy --config wrangler.toml. Wrangler is not already installed by these source files. Preview uses a NEW separate workers.dev Worker. Do not bind graphmytrade.com, www or overwrite sweet-voice-3fdf until fully tested and approved.

With SHEET_CSV_URL empty, zero products appear, and checkout stays disabled. All product URLs generated by the sheet Worker redirect externally to Instamojo. Cart is not used for those one-product checkout links.

## Notes

- Digital goods are emailed/downloaded by Instamojo, not by this Worker. This works best for PDF, Excel, ZIP and similar deliverable files. Notion sharing, bot subscriptions, externally provisioned services and license-key entitlements may require a separately verified process.
- SEO product HTML includes unique title, description, canonical URL, Product/Offer structured data and sitemap. There is no guaranteed first-page search ranking. Automatic AI-written SEO is not yet built; human-reviewed SEO fields are accepted from the sheet.
- Prices displayed on GraphMyTrade are informational; Instamojo decides the charged amount. Test that they match before approving any product.
- The merchant platform may change its fees and merchant verification. Verify directly in your merchant account.
- Do not activate any paid Cloudflare storage or GitHub Actions services for this staging workflow.
